A matrix is a set of instructions for stretching, rotating, flipping, or squishing space. It's completely determined by one thing: where it sends the two basis vectors. Everything else on the grid follows along.

Formulas

  • M = [a c / b d]
  • Mv = (ax+cy, bx+dy)
  • det(M) = ad − bc
  • |det(M)| = area scale

M = [a c / b d] is a 2×2 matrix written column by column: the first column (a, b) is where î lands after the transformation, the second column (c, d) is where ĵ lands.
Mv = (ax+cy, bx+dy) is how you apply M to any vector v = (x, y) — it's just x copies of the first column plus y copies of the second column, added together.
det(M) ("determinant") is a single number telling you how the transformation scales area. If det = 2, every shape doubles in area. If det is negative, the plane gets flipped over (like a mirror) in addition to being scaled.
area scale means the absolute value of det(M) — how much bigger or smaller areas become, ignoring any flip.

What a linear transformation means

M sends î → (1, 0) and ĵ → (0, 1)

A transformation is called linear because it keeps grid lines straight, evenly spaced, and parallel, and it always leaves the origin fixed. Since every vector is just some amount of î plus some amount of ĵ, knowing where those two land is enough to know where every single point on the plane ends up — that's the whole grid warping above.
